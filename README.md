# Branham Symbol Identity Graph

This repository hosts a lightweight static site for the Branham Symbol identity graph project. It includes pages for timeline analysis, cross-platform correlations, metadata views, and Cypher schema examples.

## Pages

- Home: `/`
- Timeline: `/timeline/`
- Timeline Diagram: `/timeline_diagram/`
- Cross-Platform Correlations: `/cross_platform/`
- Metadata: `/metadata/`
- Identity Graph: `/identity_graph/`
- Schema pages:
  - `/schema/identity_graph.cypher/`
  - `/schema/identitygraphwith_timeline.cypher/`
  - `/schema/sample_queries.cypher/`

## Local preview

Open `index.html` in a browser or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

## GitHub Pages

If the repository is published via GitHub Pages, the site will be served using the structure above.

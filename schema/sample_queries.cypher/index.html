Sample Cypher Queries

Useful starting queries for examining the graph and its relationship structure.

// Find the central person and their aliases
MATCH (p:Person {name: 'Branham Symbol'})-[:HAS_ALIAS]->(a:Alias)
RETURN p, collect(a.name) AS aliases;

// View all platforms associated with the person
MATCH (p:Person {name: 'Branham Symbol'})-[:PRESENT_ON]->(pl:Platform)
RETURN p.name, collect(pl.name) AS platforms;

// Show timeline events for the identity
MATCH (p:Person {name: 'Branham Symbol'})-[:HAS_EVENT]->(e:Event)
RETURN e.name, e.date
ORDER BY e.date;

// Search platform names by alias similarity
MATCH (a:Alias)
WHERE toLower(a.name) CONTAINS 'branham'
RETURN a.name;
